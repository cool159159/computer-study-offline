# 내 전산 학습 — 빈 앱 배포 전용

이 폴더만 GitHub에 업로드합니다. 상위 outputs 폴더 전체를 올리지 마세요.
문제·정답·후기·PDF·학습 기록은 포함하지 않습니다.

## GitHub Pages 설정
1. GitHub에서 새 공개 저장소를 만듭니다(무료 Pages용).
2. 이 폴더 안의 파일을 저장소 최상위에 업로드하고 커밋합니다.
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. 배포 완료 후 표시되는 HTTPS 주소를 Safari에서 엽니다.
5. 공유 → 홈 화면에 추가. 홈 화면 앱을 열고 별도로 보관한 개인학습자료_가져오기.json을 선택합니다.
6. 오프라인 준비 완료를 확인하고 비행기 모드에서 다시 실행해 봅니다.

## 개인 파일
개인학습자료_가져오기.json은 이 저장소에 넣지 않습니다. AirDrop 또는 파일 전송으로 각 기기에 전달하세요.
기기마다 한 번씩 가져옵니다. 풀이 기록 백업은 시험 화면에서 별도로 내보내고 가져옵니다.
홈 화면 앱과 Safari 탭의 저장 공간이 다를 수 있으므로 실제 사용할 홈 화면 앱에서 가져오세요.
학습 기록과 문제 파일은 서로 다릅니다. 서버 자동 동기화는 없습니다.
PDF는 교재별로 한 번 선택해 기기 내부에 저장합니다. 페이지 이동·앱 재실행 후 자동 연결하며 파일명·확장자 표시는 상관없습니다.

## 업데이트
앱 파일만 같은 저장소에 덮어씁니다. 문제 파일은 업데이트할 때도 업로드하지 않습니다.
자료 관리에서 앱 업데이트 확인 후 앱을 닫고 다시 엽니다.
오프라인 자료는 브라우저/운영체제가 삭제할 수 있으므로 원본과 기록 백업을 유지하세요.
현재 배포 파일은 빈 앱이며 설치 후 개인 파일을 가져와야 사용할 수 있습니다.


## 문제 자료 추가 업데이트
기존 문항·정답·모의고사가 그대로이고 연습문항만 추가된 자료는 자료 관리에서 바로 가져올 수 있습니다. 기존 문제 자료를 지울 필요가 없고 풀이 기록도 유지됩니다. 기존 자료로 만든 기록 백업도 현재 문항과 일치하는지 검사한 뒤 복원합니다.
문제·후기·출처 목록은 개인학습자료 JSON에만 넣고 이 공개 저장소에는 넣지 않습니다.

## 학습 화면 v3
공개 코드에는 PDF 원문·미리보기·문항·정답·교재별 페이지 색인을 포함하지 않습니다. 개인 JSON의 선지별 설명과 교재 위치를 읽어 화면에 표시하고, PDF는 IndexedDB에 저장한 로컬 Blob URL로만 엽니다.
연습 화면은 새 문제·오답·복습 예약 바로가기, 문제 목록, 주제별 진행률, 선지 비교, 글자 크기, 키보드 조작을 지원합니다. 메모·복습 예약은 기존 풀이 기록과 별도 로컬 백업을 제공합니다.
교재 근거는 직접 근거·관련 개념·직접 근거 미확인을 구분합니다. 관련 개념 페이지를 동일 문항의 정답 근거로 단정하지 않습니다.
