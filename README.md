# 내 전산 학습 — 빈 앱 배포 전용

이 폴더만 GitHub에 업로드합니다. 상위 outputs 폴더 전체를 올리지 마세요.
문제·정답·후기·PDF·학습 기록은 포함하지 않습니다.

## GitHub Pages 설정
1. GitHub에서 새 공개 저장소를 만듭니다(무료 Pages용).
2. 이 폴더 안의 파일을 저장소 최상위에 업로드하고 커밋합니다.
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. 배포 완료 후 표시되는 HTTPS 주소를 Safari에서 엽니다.
5. 공유 → 홈 화면에 추가. 홈 화면 앱을 열고 별도로 보관한 개인학습자료_가져오기.json을 선택합니다.
6. 오프라인 준비 완료를 확인하고 비행기 모드에서 다시 실행해 봅니다.

## 개인 파일
개인학습자료_가져오기.json은 이 저장소에 넣지 않습니다. AirDrop 또는 파일 전송으로 각 기기에 전달하세요.
기기마다 한 번씩 가져옵니다. 풀이 기록 백업은 시험 화면에서 별도로 내보내고 가져옵니다.
홈 화면 앱과 Safari 탭의 저장 공간이 다를 수 있으므로 실제 사용할 홈 화면 앱에서 가져오세요.
학습 기록과 문제 파일은 서로 다릅니다. 서버 자동 동기화는 없습니다.
PDF는 별도 선택하며 선택한 PDF는 앱 재시작 후 다시 선택해야 할 수 있습니다.

## 업데이트
앱 파일만 같은 저장소에 덮어씁니다. 문제 파일은 업데이트할 때도 업로드하지 않습니다.
자료 관리에서 앱 업데이트 확인 후 앱을 닫고 다시 엽니다.
오프라인 자료는 브라우저/운영체제가 삭제할 수 있으므로 원본과 기록 백업을 유지하세요.
현재 배포 파일은 빈 앱이며 설치 후 개인 파일을 가져와야 사용할 수 있습니다.
